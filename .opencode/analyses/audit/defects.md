## D-001 — جدول نتائج التصفّح يُعرض كأعمدة مكدّسة (`display:block`)

| | |
|---|---|
| **الشدة** | **high** — سطح التصفّح الأساسي غير مقروء: خلايا الصف تتراكب ولا تصطفّ تحت رؤوسها |
| **الموضع** | `src/app/browse/ResultsTable.tsx:40` (بناء الصنف)، `:116` (صف الرؤوس)، `:193` (صفوف البيانات) |
| **رُصد في** | `A-0199` (لقطة `.opencode/analyses/audit/shots/A-0199.jpeg`) — الصفوف تظهر كعمود ضيّق على اليمين والبقية متراكبة |
| **الحالة** | مفتوح — لم يُصلَح في مهمة التدقيق (قراءة فقط على المصادر) |

### السبب

```ts
// ResultsTable.tsx:40
const GRID = `grid-cols-[${COLUMN_IDS.map((id) => `${WIDTHS[id]}px`).join(' ')}]`;
```

عيبان مستقلان يتضافران:

1. **الصنف ديناميكي:** Tailwind يفحص المصدر نصياً وقت البناء، ولا يرى `grid-cols-[86px_…]` لأنها تُبنى وقت التشغيل ⇒ **لا تُولَّد قاعدة CSS إطلاقاً**.
2. **`display:grid` غائب:** الصفّان `:116` و`:193` يستخدمان `${GRID}` مع `items-center` فقط، بلا صنف `grid` (ولا `display:grid` في أي سلف). فالعنصر `display:block`، و`items-center` بلا أثر، و`grid-template-columns` — لو وُجد — لا يطبَّق.

النتيجة: الرؤوس والخلايا تُعرض كتلاً متتابعة عمودياً، فتتراكب مع أسماء المشاريع (كما في اللقطة).

### الإصلاح المقترح

- استبدل الصنف الديناميكي بمقاس صريح: `style={{ gridTemplateColumns: COLUMN_IDS.map((id) => \`${WIDTHS[id]}px\`).join(' ') }}` على الصفّين معاً (أو أعلن `grid-cols-[…]` حرفياً لكل مجموعة أعمدة).
- أضف `grid` إلى `className` في `:116` و`:193` (و`:113` إن أردت أن يحمل الحاوية `role=grid` العرض).
- تحقّق بصرياً: يجب أن تصطف كل خلية تحت رأسها في RTL وLTR، وأن يبقى `minWidth` والتمرير الأفقي كما هما (`:113`).

### المالك المقترح

مالك واجهة التصفّح (WS1 / `src/app/browse`) كمهمة مستقلة خارج نطاق التدقيق؛ لا تغيير على المصادر في هذه المهمة.
