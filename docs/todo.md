## تعريفُ الإنجاز لكل مهمة

```
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test -p mm-core && -p modmanager-tauri && -p mm-cli
pnpm build
```

أوّلُ نتيجة **فاشلة** تُوقِفُ المهمة. و«اختبارٌ لم يُنفَّذ» ليس نجاحًا.

## قيودٌ دائمة في هذه البيئة

- RAM حرّة منخفضة (~2 GB): البناءُ يحتاج `CARGO_PROFILE_DEV_DEBUG=0`
- قرص C: شبه ممتلئ (2.2 GB): `CARGO_TARGET_DIR` على `F:`
- WSL بلا `sudo`: **CI هو بوابةُ لينكس**، لا الجهازُ المحلّي
