# ADR 0002: توليد أنواع TypeScript بـ ts-rs

الحالة: معتمد، ويُراجَع عند صدور إصدار مستقر من tauri-specta v2

## السياق
نحتاج أنواعاً متطابقة بين Rust وTypeScript دون كتابتها يدوياً.

## القرار
نستخدم `ts-rs`. كل نوع يعبر حدّ IPC يحمل `#[derive(TS)]` و`#[ts(export)]` في `src-tauri/src/dto.rs`. تُولَّد الملفات في `src/bindings` عند تشغيل `cargo test --workspace`، وتُلتزم في المستودع، ويتحقق الـ CI من أنها محدّثة.

## السبب
- الإصدارات التي وجدتها من tauri-specta v2 ما زالت RC، وتتطلب تثبيت إصدارات دقيقة معها مكتبة Specta v2.
- ts-rs أبسط، ولا يغيّر طريقة كتابة أوامر Tauri.

## النتائج
- بعد تعديل أي DTO نشغّل `cargo test --workspace` ونلتزم الملفات المولَّدة.
- الأنواع ذات 64 بت تُعلَّم `#[ts(type = "number")]` لأن ts-rs يحوّلها افتراضياً إلى bigint.
