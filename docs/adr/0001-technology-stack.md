# ADR 0001: الحزمة التقنية

الحالة: معتمد

## السياق
نعيد كتابة مدير المودات والمود باكات (كان بلغة بايثون) كتطبيق سطح مكتب لويندوز ولينكس، بأداء عالٍ وواجهة جميلة وقابلية للتطور.

## القرار
- Tauri 2 غلافاً للتطبيق.
- نواة Rust مستقلة عن الواجهة (`core`)، وأداة CLI فوقها.
- React + TypeScript + Vite للواجهة، مع Tailwind CSS 4 وshadcn/ui.
- SQLite عبر rusqlite داخل النواة.

## البدائل المرفوضة
- Electron: ثقيل في الحجم والذاكرة.
- Avalonia: أقل مرونة في التصميم من الويب.
- SolidJS: أسرع في التحديثات الدقيقة، لكن مكتباته أقل، واخترنا React لأنه أقل احتكاكاً أثناء تعلّم Rust.

## النتائج
- الواجهة طبقة قابلة للاستبدال لأن كل المنطق في النواة.
- تعلّم Rust هو أكبر مخاطرة؛ نبدأ بالنواة وCLI قبل الواجهة.
